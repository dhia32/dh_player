📺 DHPlayer – IPTV & Media Player for Windows

DHPlayer is a modern and powerful IPTV & media player for Windows, built to deliver a smooth, immersive viewing experience with a clean dark UI and high-performance playback.

✨ Features

🎬 Modern dark UI (True Black – Netflix-like experience)

🎨 Glassmorphism UI redesign with full-page Movie Detail view

🚀 Powered by MPV engine (SD / HD / FHD / 4K support)

📡 Full IPTV support (Xtream Codes & M3U playlists)

🌍 11,000+ free global TV channels (IPTV-ORG)

📺 Live TV with EPG support

🔲 Multi-View mode (watch up to 4 live streams simultaneously)

🎞 Movies & Series libraries with posters and metadata

📝 Automatic subtitle search & download

🔊 Multiple audio tracks & subtitle support

📺 Cast support (Smart TVs & Chromecast)

⚙️ Multi-server & multi-account management

🌐 Multi-language UI (Arabic & English)
